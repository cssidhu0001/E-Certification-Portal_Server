# E-Certification Portal 🎓

A web-based **E-Certification Portal** designed to simplify and automate the certificate issuance process. Users can register and submit their details for verification. Administrators can review applications, approve or reject requests, and generate certificates automatically for approved users.

## ✨ Features

* 📝 **User Registration:** Users can register and submit their details for certificate issuance.
* 🔐 **Admin Verification:** Admin can review and verify submitted applications.
* ✅ **Approval & Rejection:** Admin can approve or reject certificate requests.
* 📄 **Automated Certificate Generation:** Generate PDF certificates for approved users.
* 📥 **Certificate Download:** Users can download their approved certificates.
* 🔳 **QR Code Integration:** Certificates include QR codes for online verification.
* 🆔 **Unique Certificate ID:** Every generated certificate has a unique identification number.
* 🔍 **Certificate Verification:** Verify certificate authenticity through a dedicated verification link.
* 🚫 **Duplicate Prevention:** Prevent duplicate certificate issuance for the same registered email.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **PDF Generation:** Puppeteer
* **QR Code:** QRCode
* **Other Tools:** JavaScript, REST API

## ⚙️ How It Works

1. **Register:** Users submit their details through the portal.
2. **Review:** Admin reviews the submitted applications.
3. **Verify:** Admin approves or rejects each application.
4. **Generate:** Upon approval, the system generates a PDF certificate with a unique ID and QR code.
5. **Download:** Approved users can download their certificates.
6. **Verify:** Anyone can scan the QR code to verify the certificate online.

## 🚀 Project Objective

The main objective of this project is to digitize and streamline the certificate distribution process by reducing manual work, simplifying administrative verification, and providing a convenient way to issue and verify digital certificates.
